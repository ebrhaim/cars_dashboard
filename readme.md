# Cars Database Project

## Overview
This project explores and analyzes a cars trading shop dataset originally sourced from **Kaggle**.  
The dataset was imported into **phpMyAdmin** as a simulation of a website database, then processed with SQL for cleaning and transformation. Additional **views** were created to enhance usability.  

After cleaning, the database was connected to **Excel pivot tables and pivot charts**, making the data interactive and reflective of real‑time status for exploration and visualization.

## Workflow
1. **Data Source**: Kaggle cars trading shop dataset.  
2. **Simulation**: Imported into phpMyAdmin to mimic a live website database.  
3. **Processing**: SQL cleaning, transformations, and creation of views.  
4. **Analysis**: Connected to Excel pivot tables/charts for interactive exploration.  
5. **Visualization**: Dashboards designed to highlight trends, categories, and performance metrics.
